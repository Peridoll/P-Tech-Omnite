# Omnite Shops

工具箱の「ショップ管理」から、一般ショップを設置します。ショップ機能は ptech_omnite_toolbox 内に実装し、配達機能は ptech_omnite_delivery が担当します。

## 起動

ox_inventory / ox_target / ox_lib / oxmysql / qbx_core の後に ptech_omnite_toolbox を起動してください。ショップ用の別リソースは不要です。
管理操作には工具箱 `pomnite_toolbox` と `admin` / `god` / `omnite.shops.admin` のいずれかのACE権限が必要です。

## 操作

- 設置画面を開いた時点の自分の足元と向きへ配置します。既存ショップは「自分の足元・向きへ配置する」を選ぶと移動します。
- ターゲットの店舗名を選ぶと購入画面を直接開きます。設定画面は工具箱に集約します。有限在庫の店舗ではadminまたは在庫管理JOBに「在庫を補充する」が表示されます。無限在庫の商品一覧はadminが工具箱から編集します。売上金庫は「金庫を開く」ターゲットから利用します。利用権限の設定は工具箱で行います。
- アクセスポイントにNPCを置くか、ターゲットだけを置くかを選択。NPCモデルは後から変更できます。
- 購入可能JOB・在庫管理JOBは、それぞれJOB一覧から複数選択できます。購入制限なしも選択可能。在庫管理JOBの未選択はadminのみ。既存の単一JOB設定は引き継ぎます。勤務状態は問いません。
- 購入JOB制限ありの場合、JOB選択後にそれぞれの購入可能な最低階級を設定します。既存ショップは管理メニューの「JOB別の販売可能階級」から直接変更できます。その階級以上が購入可能。既存ショップは初期値0で、購入画面を開く時と購入時にサーバーで再判定します。
- 商品スタッシュ（500スロット・100,000kg）へ実物を入れ、「商品リスト・販売価格」で商品を選び、販売可否と現金価格を設定します。同画面の「商品を登録・補充する」から登録スタッシュも開けます。初期値は販売不可。
- メタデータが違うアイテムは別商品。売り切れ後も設定を保持し、同じアイテム・メタデータを再投入すると設定を引き継ぎます。
- スタッシュのスロット順が販売画面の順番です。
- 有限在庫は実物を消費。無限在庫は実物を陳列用として保持し、購入しても減りません。
- 在庫管理JOBは補充・取り出し可能。金庫は初期状態では在庫管理JOBの `isboss` の人のみ利用できます。「金庫を開く権限を設定」で複数JOB・JOBごとの最低階級・店長限定の有無を個別設定できます。個別設定のJOBが未選択の場合は誰も開けられません。既存店舗は従来の店長限定設定を引き継ぎます。
- 売上スタッシュはmoney以外を受け付けません。現金購入成功時だけ売上を格納します。
- 削除時は実物と売上金を削除したadminへ返却し、持ちきれない分は足元にドロップします。無限在庫も実際に登録した個数のみ返却します。
- マップブリップはありません。

## 保存・検証

DBテーブル `ptech_omnite_shops` は自動作成します。在庫・売上の実物はox_inventoryの永続スタッシュで保存されます。
現環境のox_inventoryにあるpost-hookイベント（registerHookの戻り値をイベント名にしてsuccessを受け取る拡張）を購入確定に使用します。拡張のない別バージョンに差し替える場合は購入連携の変更が必要です。
在庫・売上の保存タイミングはox_inventory側の保存仕様に従います。実機では購入成功／拒否、同時購入、補充、再起動、モデル変更、ショップ削除を確認してください。

テスト：`node dev/shops.cjs`（luaparse / fengariが必要）

既存のショップDBテーブル・スタッシュID・イベント名は互換性のため保持します。保存先のIDに shops の名前が含まれていても、リソース本体は toolbox です。

## 固定販売価格とox_inventoryの価格変動

工具箱ショップは登録時に randomprices=false を指定します。ox_inventory標準の価格変動が有効な場合、この指定を扱う互換修正も必要です。工具箱フォルダを作業ディレクトリにして、実際に使用するox_inventoryを指定します。

```powershell
node install/patch-ox-shop-prices.cjs "実際のox_inventoryフォルダ"
```

変更対象は modules/shops/server.lua の3箇所のみ。バックアップを自動作成し、既知の形と一致しない場合は書き込みません。適用後は ox_inventory、ptech_omnite_toolbox の順に再起動します。通常のショップは従来の価格変動設定を維持します。

互換テスト：node dev/shops.cjs "ox_inventoryフォルダ"。実際のショップ登録関数を使い、価格変動が有効でも工具箱ショップが設定価格になることを検証します。
