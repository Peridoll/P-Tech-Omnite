# サークルエリア

工具箱の「サークルエリアの管理」から新規設置します。管理者判定は既存の `Config.Placement.adminAce`（初期値 `omnite.seating.admin`）を使用します。新規サークルは無効状態で作成画面が開きます。

- 名前・半径・範囲外メッセージ・連れ戻し秒数・有効状態を設定し、保存します。メッセージの `{seconds}` は残り秒数に置き換わります。
- 中心（編集ポイント）と連れ戻し先は、各メニューを選んで現地に移動し、Eで記録します。Escで記録を中止します。連れ戻し先はサークル内に指定してください。
- 設定は `ptech_omnite_circles` に自動保存され、リソース再起動時に復元されます。テーブルは自動作成します。
- 有効中だけマップ・ミニマップへ範囲を表示します。編集ポイントは無効中も利用できます。
- 範囲判定は高さを除いた水平距離です。同じルーティングバケット内で、一度入ったプレイヤーを対象にします。外へ出ると警告・カウントを開始し、再入場で解除します。時間切れで指定先へ戻します。
- 無効化・削除・バケット変更で拘束を解除します。有効なまま設定を変更した場合、対象者を維持してカウントをリセットします。

## 脱出パスワード

全員が編集ポイントでEを押せます。一般プレイヤーは「脱出パスワード」の入力欄が開き、管理者は編集メニューの先頭から同じ入力欄を開けます。

`4155` でレギオン広場付近へ移動します。移動先は `Config.Circles.escapeDestination` で調整できます。パスワード判定・ポイントとの距離・バケット・入力頻度はサーバーで検証します。パスワードはサーバースクリプト内のみで保持します。

脱出時は重複エリアを含む現在の拘束を解除します。その後サークルへ入り直すと再び対象になります。移動先がサークル内の場合、そのサークルから一度出るまでは再拘束しません。

## 実機確認

`restart ptech_omnite_toolbox` 後、管理者と一般プレイヤーでターゲット操作・誤入力・正しいパスワード・範囲外カウント・再入場・車両搭乗中の連れ戻し・マップ表示・DB復元を確認してください。レギオンの座標は標準マップ基準です。独自MLOや配置物がある場合は移動先を調整してください。

## サークル内の初期キャラ設定

有効なサークルの半径内で、徒歩で立っている状態ならEキーで初期キャラ設定を開けます。中心からの水平距離で判定し、中心のターゲットアクセスとは別の操作です。illenium-appearance の startPlayerCustomization export で全項目編集画面を現在の外見を保持して開き、確定時に saveAppearance へ保存します。ショップの所持金照会は経由しません。Gキーは既存の顔コード発行・読み込みメニューを開きます。ほかのUI表示中や管理モード中は開きません。サーバーでも有効状態・範囲・バケットを検証します。
