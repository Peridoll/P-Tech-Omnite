# Omnite Shops

工具箱の「ショップ管理」から、一般ショップを設置します。ショップ機能は ptech_omnite_toolbox 内に実装し、配達機能は ptech_omnite_delivery が担当します。

## 起動

ox_inventory / ox_target / ox_lib / oxmysql / qbx_core の後に ptech_omnite_toolbox を起動してください。ショップ用の別リソースは不要です。
管理操作には工具箱 `pomnite_toolbox` と `admin` / `god` / `omnite.shops.admin` のいずれかのACE権限が必要です。

## 操作

- アクセスポイントにNPCを置くか、ターゲットだけを置くかを選択。NPCモデルは後から変更できます。
- 購入JOB制限は任意。在庫管理JOBとは別設定です。勤務状態は問いません。
- 商品スタッシュ（500スロット・100,000kg）へ実物を入れ、商品詳細設定で販売可否と現金価格を設定します。初期値は販売不可。
- メタデータが違うアイテムは別商品。売り切れ後も設定を保持し、同じアイテム・メタデータを再投入すると設定を引き継ぎます。
- スタッシュのスロット順が販売画面の順番です。
- 有限在庫は実物を消費。無限在庫は実物を陳列用として保持し、購入しても減りません。
- 在庫管理JOBは補充・取り出し可能。売上スタッシュはそのJOBの `isboss` の人のみ利用できます。
- 売上スタッシュはmoney以外を受け付けません。現金購入成功時だけ売上を格納します。
- 削除時は実物と売上金を削除したadminへ返却し、持ちきれない分は足元にドロップします。無限在庫も実際に登録した個数のみ返却します。
- マップブリップはありません。

## 保存・検証

DBテーブル `ptech_omnite_shops` は自動作成します。在庫・売上の実物はox_inventoryの永続スタッシュで保存されます。
現環境のox_inventoryにあるpost-hookイベント（registerHookの戻り値をイベント名にしてsuccessを受け取る拡張）を購入確定に使用します。拡張のない別バージョンに差し替える場合は購入連携の変更が必要です。
在庫・売上の保存タイミングはox_inventory側の保存仕様に従います。実機では購入成功／拒否、同時購入、補充、再起動、モデル変更、ショップ削除を確認してください。

テスト：`node dev/shops.cjs`（luaparse / fengariが必要）

既存のショップDBテーブル・スタッシュID・イベント名は互換性のため保持します。保存先のIDに shops の名前が含まれていても、リソース本体は toolbox です。
