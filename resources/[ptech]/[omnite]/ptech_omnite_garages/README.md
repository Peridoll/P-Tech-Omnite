# Omnite ガレージ位置指定 0.1.0-dev

Omini工具箱から、JG Advanced Garages v3の既存ガレージの受付・出庫位置を指定し、Config用の設定行をコピーする補助リソースです。v4の動的登録APIは使用しません。

## 導入

`ptech_omnite_garages`を他のOmniteリソースと同じ階層へ置き、JG・ox_lib・ox_inventoryの後に`ensure ptech_omnite_garages`を追加します。Seatingの工具箱メニュー更新分も反映してください。アイテム定義の変更は不要です。

## 操作

工具箱を使う→「ガレージの管理」→既存ガレージを選択します。表示対象はJGの利用可能地点一覧です。

- 「受付位置を指定」：現地へ移動してEで確定。Escで中止。
- 「出庫位置を追加」：車に乗って位置・向きを決め、Eで確定できます。
- 「出庫位置を編集・削除」：既存位置を取り直す、数値で編集する、不要な出庫位置を削除する操作です。
- 「Config形式でコピー」：受付と出庫位置だけを変更するLua設定行をコピーします。

既存の出庫位置を最初に取り込むため、変更しない地点も残せます。新規追加と置き換えは別の操作です。空きスロットの優先順位は表示順です。

出力した行を、サーバーの`jg-advancedgarages/config/config.lua`で該当テーブルの定義より後に追加し、JGを再起動して反映します。ガレージ名を変更せず、所有車両やJOB権限の設定には触れません。元の設定をバックアップしてから反映してください。

この版は位置の採取・数値編集・Config出力までです。操作中の値は一時的な下書きで、DB保存やJGへの即時反映は行いません。新しいガレージそのものの作成・車両の移動・所有者変更も対象外です。

利用には設定アイテム`pomnite_toolbox`の所持をサーバー側でも確認します。実機で受付・入庫・出庫を確認するまでは本番のガレージ設定へ適用しないでください。
