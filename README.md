# P-Tech Omnite

P-Tech Omnite は、FiveM ロールプレイサーバー向けの共通ユーティリティリソース群です。特定の職業や業務に限定されず、店舗・組織・市民が共通して利用できる機能を、独立したリソースとして開発します。

リソース名は `ptech_omnite_<module>` を使用します。

## リソース

| リソース | 概要 | 状態 |
|---|---|---|
| `ptech_omnite_seating` | ワールド内の椅子に座る機能 | 開発中 |
| `ptech_omnite_requests` | 一般依頼・ジョブ依頼を扱う依頼ボード | 設計中 |

各リソースの導入方法や動作条件は、それぞれのリソース内の資料を参照してください。
